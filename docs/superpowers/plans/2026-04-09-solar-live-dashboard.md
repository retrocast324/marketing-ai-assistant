# Solar.live - Real-Time Photovoltaic Intelligence Dashboard

## Overview

Created a new standalone Next.js real-time solar energy intelligence dashboard inspired by worldmonitor, with NOVERA luxury design and Cerebras LLM AI chat integration.

## Links

- **GitHub**: https://github.com/mahdi1234-hub/solar.live
- **Live URL**: https://solarlive-umber.vercel.app

## Features (inspired by worldmonitor)

### Dashboard Widgets
- **Solar Market Overview** - Global installed capacity, module prices, polysilicon prices, LCOE, generation data
- **Live Solar News Feed** - 10+ categorized news items (Installation, Technology, Market, Policy, Storage, Grid, Investment)
- **Stock Ticker Bar** - Scrolling ticker with solar stocks (ENPH, SEDG, FSLR, JKS, CSIQ, RUN, MAXN, DQ, ARRY, NOVA)
- **Global Solar Irradiance** - Bar chart showing kWh/m2/yr by region
- **Top Solar Nations** - Installed capacity by country with progress bars
- **Technology Breakthroughs** - Latest cell efficiency records (Perovskite, HJT, TOPCon, CdTe, Organic, CIGS)
- **Policy & Regulation Tracker** - Active policies by country with impact ratings
- **Solar Generation by Region** - TWh/yr breakdown by global region

### AI Chat (Cerebras LLM)
- Floating chat panel with solar AI analyst persona
- Powered by Cerebras llama3.1-8b model (always-on cloud API)
- System prompt with full dashboard context data
- Real-time streaming responses via SSE
- Suggestion prompts for quick queries

### Design (NOVERA-inspired)
- Full-screen luxury background image with dark overlay
- Glassmorphism widget cards (backdrop-blur, white/3 bg)
- Solar amber accent color (#fbbf24)
- 9-10px uppercase tracking-widest labels
- 2px border-radius (architectural minimal)
- Serif headings, mono data, sans body
- Animated ticker scroll, pulse-glow effects
- Live indicator with pulsing dot
